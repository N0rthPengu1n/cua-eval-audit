# 五题 Agent 首轮运行记录

每题使用单独的 Codex CLI 会话。原评分复用了 OSWorld 的评分函数和固定参考资产，评分范围为最终文件。原评分分支值、文件摘要和日志摘要见 [逐题评分记录](agent_run_01.json)。

| 题目 | 原评分 | 复核结果 |
|---|---:|---|
| p3 矩阵转置 | 1 | Agent 将工作簿保存到子目录。按最终消息定位文件后，将内容相同的副本放到评分路径。 |
| p6 发票号透视表 | 1 | 首次启动因 PowerShell 拆分题面引号而退出。通过标准输入重跑后生成透视表，核实 18 行源数据对应的 6 个发票号计数均正确。 |
| p8 标题样式 | 0 | 标题已加粗、设为 44 pt 并带下划线。原评分要求金标文本框高度，导致该产物被拒。 |
| p9 表格首行 | 1 | 正确产物通过原评分。 |
| p10 图片铺满并居中 | 1 | 使用裁切后的可见图像比例检查，修正原型也给 1 分。 |

## p8 的误拒证据

第 1 页标题框在初始稿和 Agent 产物中均为 1,333,440 EMU 高，第一份金标为 3,999,960 EMU。保留其他检查，仅关闭几何检查，两个金标分支均从 0 变为 1。在另一个受控副本里，只把标题框高度改成第一份金标的高度，该分支也从 0 变为 1。以上修改用于定位拒绝原因，逐题评分仍保留原产物的 0 分。
